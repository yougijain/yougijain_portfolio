Oct 2026 Inference / Performance

tinyinfer — CNN Inference Engine in C++

A CIFAR-10 classifier trained in PyTorch and run by a from-scratch C++ engine that agrees with PyTorch on 10,000 of 10,000 test predictions. The matrix multiply under every convolution goes from a naive triple loop to a packed, register-blocked AVX2/NEON micro-kernel on all cores, and an INT8 path with per-channel scales runs 1.5× faster than FP32 at the same accuracy. Every speedup is a median of repeated runs, placed on a measured roofline and chased down with gprof and callgrind.

Sep 2026 Live ML / Calibrated Risk Model

NYC Collisions — Injury-Risk Model & Watchlist

A gradient-boosted model scores how likely each of 637K NYC crashes was to injure someone from what was involved — never where — so intersections can be ranked by how far they run above their own crash mix. Time-split train/calibrate/test folds, a log-odds shift for reporting drift, out-of-sample scoring, and a backtest against a permutation null that admits where the model only ties a naive ranking. The pipeline refreshes, retrains, and re-scores itself every week.

Jun 2026 Experimentation / Causal

When Average Effects Lie

Turns a 64,000-customer randomized email A/B test into a targeting strategy. The Women's email's +4.5pp average visit lift is really +7.3pp for prior women's-merch buyers and +1.1pp for everyone else. Balance checks, Lin-adjusted effects, FDR-corrected interactions, and T-, S-, and DR-learners chosen by cross-fitted Qini yield a policy worth +$16.95 per 1,000 customers (95% bootstrap interval +$2.99 to +$30.60) while sending 41% fewer emails.

Sep 2026 Live Applied Statistics

Crate Intelligence — Spotify Listening Analysis

A DJ's questions run as product analytics over Spotify history in DuckDB. Shuffle drives both skips and clashing key changes, so the harmonic-mixing test is a Cochran–Mantel–Haenszel stratified on shuffle; on the bundled synthetic sample, pooling would overstate the clash effect by 38%. Tracks rank on Wilson lower bounds, and a beam-search set builder is benchmarked against greedy and 200 random orderings. The whole pipeline runs on that sample, so no personal data is committed.
